# MyPaint

Учебный графический редактор: C#, Windows Forms, .NET 8, System.Drawing.
Внешние NuGet-пакеты не используются.

## Запуск

Откройте Paint.sln в Visual Studio 2022 с поддержкой .NET 8 и компонентом
«Разработка классических приложений .NET», затем нажмите F5.

Командная строка:

    dotnet build Paint.sln -c Release
    dotnet run --project Paint.csproj

## Возможности

- Приложение запускается развёрнутым; белый холст расположен на сером фоне
  рабочей области с полями, тонкой границей и лёгкой тенью.
- Светлое оформление с салатовым акцентом: одинаковые кнопки с иконками,
  подсказки с названиями и горячими клавишами, подсветка наведения/нажатия/выбора,
  номера страниц в виде вкладок. Иконки рисуются средствами System.Drawing.
  Окна Settings и Plain Text используют общие цвета и плоские кнопки.
- Ctrl + колесо мыши над холстом увеличивает/уменьшает масштаб от 10% до 800%.
  Деления до 200%: 10, 25, 50, 75, 100, 125, 150, 200%; далее шаг составляет 50%.
  Масштаб показан в строке состояния и запоминается отдельно для каждой страницы.
  Увеличение происходит вокруг указателя; обычное колесо прокручивает по вертикали,
  Shift + колесо — по горизонтали. Если доступна только горизонтальная прокрутка,
  обычное колесо также перемещает холст по горизонтали.
  Масштаб меняет только отображение: размер Bitmap, сохранённого файла и история
  остаются прежними. Рисование, выделение, перемещение и текст учитывают масштаб.
  Во время активного рисования с нажатой кнопкой мыши масштаб не меняется.
- Размер нового холста определяется доступной областью окна.
- Mouse, Pencil, Eraser, Line, Rectangle, Ellipse, Plain Text, Fill, Select Area.
- «Мышь» (V) — первый инструмент с иконкой стрелки и обычным курсором.
  При наличии полос прокрутки зажмите левую кнопку на холсте или сером фоне
  и перетаскивайте вид в любом направлении. Рисунок, история Undo и признак
  несохранённых изменений не меняются. Отпускание кнопки, Esc, потеря захвата
  или смена инструмента завершают перетаскивание. Если холст помещается в окно,
  щелчок этим инструментом ничего не рисует и не выделяет.
- Подсказки кнопок инструментов показывают клавиши: V — Mouse, P — Pencil, E — Eraser,
  L — Line, R — Rectangle, O — Ellipse, T — Plain Text, F — Fill,
  S — Select Area (без Ctrl).
- Plain Text (T): выделите прямоугольник на холсте мышью и печатайте внутри него.
  В плавающем окне справа выбираются шрифт, размер (8–100 px), отдельные цвета текста и фона,
  выравнивание по ширине (слева / по центру / справа) и по высоте
  (сверху / по центру / снизу). Эти параметры можно менять во время ввода.
  Фон выбранного цвета заполняет весь текстовый прямоугольник при применении.
  Текст и фон отменяются одним Undo; отмена через Esc не меняет рисунок.
  Enter добавляет новую строку, Ctrl+Enter применяет текст, Esc отменяет ввод.
  Щелчок вне текстового поля, смена инструмента, сохранение или переключение вкладки
  применяют текст. Во время ввода буквы P/E/L/R/O/T/F/S вводятся как обычный текст.
  Текст переносится по ширине поля и записывается в Bitmap в пределах выбранной области.
- Окно настроек Plain Text появляется справа над холстом при выборе T.
  Оно не блокирует рисование и ввод текста. Перетаскивайте окно за заголовок;
  положение сохраняется при смене инструмента в текущем запуске приложения.
  При выборе другого инструмента окно скрывается.
- Settings → «Загрузить шрифт…» позволяет выбрать файл TTF/OTF и добавляет шрифт в список.
  Загруженные файлы копируются в Рабочий стол\mypaint\fonts и загружаются
  при следующих запусках MyPaint. Шрифты подключаются для процесса приложения,
  без установки в системную папку Windows. Неподдерживаемые и повреждённые файлы
  отклоняются с сообщением об ошибке.
- Fill: щёлкните по области, чтобы залить её текущим цветом. Заливаются связанные
  по горизонтали и вертикали пиксели одинакового цвета.
- Select Area (S): выделите прямоугольную область мышью в любом направлении.
  Границы отображаются пунктиром, внутри — полупрозрачная серая подсветка.
  Eraser (E), Erase Selection или Del удаляют выделенную область белым цветом.
  Fill (F) закрашивает всю выделенную область выбранным цветом.
  Для перемещения захватите выделение мышью изнутри и перетащите его.
  Переносятся все пиксели выделенного прямоугольника, включая его фон;
  на прежнем месте остаётся белая область. Перемещение ограничено краями холста.
  Отпускание мыши применяет перемещение, Esc во время перетаскивания отменяет его.
  Перемещение поддерживает Undo/Redo как одно действие.
  Esc снимает выделение; щелчок без перетаскивания в Select Area также снимает его.
  Выбор остальных инструментов снимает выделение. Выделение хранится отдельно для каждой вкладки.
- ColorDialog для выбора цвета; кнопка Color показывает образец рядом с подписью.
  Кнопки цветов текста и фона используют такие же образцы.
- Толщина карандаша, фигур и ластика от 1 до 100 px: числовое поле и связанный ползунок.
  Ползунок оформлен салатовой дорожкой и круглым бегунком с подсветкой наведения.
- Предпросмотр фигуры до отпускания мыши.
- New создаёт независимый белый холст в новой вкладке.
- Строка №1: File, Settings, вкладки с номерами. Edit скрыт;
  New и Save As доступны в File без повторных кнопок в верхней строке.
- Номера вкладок увеличены в 1,5 раза; активная вкладка подсвечивается
  полупрозрачным салатовым цветом. Правая кнопка мыши по номеру открывает
  Delete (закрыть страницу) и Copy (создать независимую копию на новой странице).
  Копия имеет собственный Bitmap, пустую историю и сохраняется в новый файл.
  После удаления последней страницы создаётся новый белый холст.
- Перед переходом на другую страницу, созданием новой страницы/копии,
  открытием изображения, закрытием страницы или приложения редактор предлагает
  сохранить несохранённые изменения: «Да», «Нет» или «Отмена».
  Отмена диалога сохранения и ошибка записи также отменяют переход/закрытие.
  При переходе с ответом «Нет» рисунок остаётся в памяти исходной страницы;
  при её удалении изменения теряются. Звёздочка в заголовке обозначает изменения.
- Строка №2: инструменты рисования, Clear, Undo и Redo.
- Строка №3: толщина, ползунок, текущая толщина и кнопка Color.
- Clear с подтверждением, Open, Save и Save As для PNG, JPG и BMP.
- Undo/Redo на 20 действий отдельно для каждой вкладки, включая очистку.
- Строка состояния: инструмент, цвет, толщина, координаты.
- Settings позволяет выбрать размер холста (1–4096 px по каждой стороне)
  или размер по окну, а также папку рисунков (по умолчанию Рабочий стол\mypaint\drawings).
  Здесь также находится кнопка «Загрузить шрифт…» без отображения пути папки шрифтов.
  Размер применяется к текущей вкладке и новым холстам. Существующий рисунок
  сохраняется без масштабирования в левом верхнем углу; при уменьшении края
  обрезаются. Изменение размера можно отменить через Undo.
  Настройки сохраняются между запусками.
- Окно Plain Text использует автоматическую компоновку, а кнопки — размеры
  по содержимому, чтобы текст и выбор шрифта не обрезались при масштабировании Windows.
- Ctrl+N — новый холст, Ctrl+O — открыть, Ctrl+S — сохранить,
  Ctrl+Shift+S — сохранить как, Ctrl+Z — Undo, Ctrl+Y — Redo.

## Как устроен код

Program.cs запускает Form1. Form1.Designer.cs создаёт меню, панель инструментов,
PictureBox, выбор толщины и StatusStrip. ToolType.cs содержит перечисление инструментов.
UiTheme.cs содержит палитру, оформление обычных элементов и ColorSampleButton
с образцом цвета. ToolIcons.cs рисует иконки инструментов; форма освобождает
их Bitmap при закрытии. PageMenuRenderer оформляет меню, вкладки и состояния
кнопок панели инструментов. Размеры иконок и кнопок учитывают DPI Windows.
ThemedTrackBar.cs меняет отрисовку стандартного TrackBar через NM_CUSTOMDRAW,
сохраняя встроенное управление мышью, клавиатурой и события ValueChanged.
В Form1.cs находятся обработчики и логика редактора.
TextInputDialog.cs сохраняет прежнее окно ввода текста и размера шрифта.
ShowLegacyTextDialog оставлен как альтернативный способ ввода, но не вызывается
инструментом Plain Text.
TextOptionsForm.cs — отдельное немодальное окно с настройками текста.
ShowTextOptions размещает его справа при первом открытии. Стандартный заголовок
FixedToolWindow обеспечивает перетаскивание окна. Ctrl+Enter и Esc из этого окна
передаются главной форме, чтобы можно было применить или отменить ввод текста.
TextFonts.cs хранит установленные и загруженные семейства шрифтов. Для рисования
в Bitmap используется PrivateFontCollection; для отображения в стандартном
TextBox — AddFontResourceEx с флагом FR_PRIVATE. Dispose освобождает FontFamily,
коллекции и подключённые ресурсы GDI через RemoveFontResourceEx.
SettingsDialog.cs — окно настроек. AppSettings.cs читает и сохраняет настройки
в %LOCALAPPDATA%\MyPaint\settings.json с помощью стандартного System.Text.Json.
AppSettings задаёт общую папку на рабочем столе и подпапки drawings/fonts.
Прежний путь сохранения в корень mypaint автоматически заменяется на drawings;
пользовательские папки сохранения сохраняются. TextFonts копирует ранее загруженные
шрифты из старой папки %LOCALAPPDATA%\MyPaint\Fonts в новую fonts,
не удаляя исходные файлы и не перезаписывая существующие копии.
DrawingDocument.cs — простой класс данных отдельной вкладки: номер, Bitmap,
путь к файлу и два стека истории. Список documents хранит все открытые вкладки.
SwitchDocument проверяет несохранённые изменения через ConfirmLeavingDocument,
а ActivateDocument меняет текущий документ и изображение в PictureBox.
CopyDocument клонирует Bitmap, CloseDocument закрывает выбранную страницу
после подтверждения сохранения. OnFormClosing проверяет все страницы.
PageMenuRenderer рисует полупрозрачную подсветку активного номера.
DrawingDocument.ZoomIndex хранит выбранный масштаб. ZoomCanvas меняет размер
PictureBox с режимом StretchImage и прокрутку, удерживая точку под указателем.
PreFilterMessage обрабатывает колесо над холстом, включая ввод текста:
Ctrl вызывает ZoomCanvas, обычное колесо и Shift вызывают ScrollCanvas.
Это обеспечивает прокрутку и при фокусе в PictureBox.
SetCanvasScrollPosition ограничивает прокрутку границами рабочей области.
BeginCanvasPan/UpdateCanvasPan/EndCanvasPan управляют захватом мыши и
перетаскиванием вида. Координаты перетаскивания вычисляются относительно
неподвижной панели, поскольку PictureBox перемещается при прокрутке.
ToCanvasPoint переводит координаты мыши в пиксели Bitmap; Canvas_Paint применяет
ScaleTransform к предпросмотру. Текстовое поле и его шрифт масштабируются отдельно;
при подтверждении текст рисуется в исходном размере в Bitmap.
DrawingDocument.Selection хранит границы выделения. Canvas_Paint отображает
подсветку и пунктир поверх изображения; они не записываются в Bitmap и не
попадают в сохранённый файл. PaintSelection изменяет только выделенный прямоугольник
и сохраняет предыдущее состояние для Undo.

Свойство canvasBitmap возвращает рисунок текущего документа. PictureBox.Image ссылается на этот Bitmap,
поэтому рисунок сохраняется при перерисовке окна. Graphics.FromImage создаётся
на время операции и освобождается через using, как и Pen и Brush.

Canvas_MouseDown начинает действие и запоминает начальную точку.
Canvas_MouseMove соединяет соседние точки карандаша/ластика; для фигур обновляет
конечную точку предпросмотра. Canvas_MouseUp завершает действие.
Canvas_Paint отображает временный предпросмотр фигуры. FinishDrawing записывает
завершённую фигуру в Bitmap. Math.Min и Math.Abs позволяют рисовать в любом направлении.
Потеря захвата мыши также завершает текущее действие.
ProcessCmdKey переключает инструменты по горячим клавишам.
Для заливки достаточно MouseDown. DrawTextAtPoint записывает текст
в Bitmap через Graphics.DrawString в старом варианте ввода.
В текущем Plain Text события MouseDown/Move/Up задают прямоугольную область,
BeginInlineText создаёт многострочный TextBox поверх PictureBox.
TextBox находится внутри панели размером с текстовый прямоугольник. TextAlign
задаёт горизонтальное выравнивание, UpdateInlineTextLayout меняет его положение
по вертикали в зависимости от высоты текста. GetTextLayoutBounds вычисляет
размещение текста как для поля ввода, так и для сохранения в Bitmap.
FinishInlineText освобождает поле ввода и при подтверждении записывает текст
и выбранный фон в Bitmap с ограничением Graphics.SetClip. Для горизонтального
выравнивания при рисовании используется StringFormat.Alignment.
История сохраняется один раз перед
применением текста; Esc и пустой текст не меняют рисунок и историю.
FillArea использует очередь и массив пикселей,
полученный через LockBits; каждый подходящий пиксель посещается один раз.
Очередь позволяет заливать большие области без рекурсивных вызовов.
Оба инструмента сохраняют состояние для Undo. Пустой текст и заливка тем же цветом
не добавляют действие в историю.

При перетаскивании выделения movingBitmap хранит копию его исходных пикселей.
Canvas_Paint показывает белую область на старом месте и копию в новом месте,
не изменяя исходный Bitmap. FinishDrawing при отпускании мыши сохраняет историю,
очищает исходный прямоугольник и вставляет копию на новом месте. Копия позволяет
корректно переносить область даже при перекрытии старого и нового положения.
CancelSelectionMove отменяет предпросмотр без изменения Bitmap.

SaveUndoState сохраняет копию Bitmap перед изменением рисунка и очищает redoStack.
Для свободной линии копия создаётся перед первым штрихом, поэтому весь жест мышью
отменяется одним действием. Undo переносит копию текущего рисунка в redoStack и
восстанавливает состояние из undoStack. Redo делает обратное. Старые состояния
за пределами 20 записей освобождаются через Dispose.
CurrentVersion и SavedVersion позволяют определить несохранённые изменения.
Номера состояний сохраняются рядом с Bitmap в UndoVersions/RedoVersions;
Undo/Redo восстанавливают номер вместе с изображением. Возврат к сохранённому
состоянию снимает признак изменений. LastVersion растёт при каждом новом действии,
поэтому новое действие после Undo не совпадает по номеру с сохранённым состоянием.

SelectTool меняет currentTool и отмечает кнопку активного инструмента.
CreateDrawingPen задаёт цвет, толщину и скруглённые концы линии.
Ластик рисует белым цветом; для него используется тот же регулятор толщины.
SetBrushWidth синхронизирует NumericUpDown и TrackBar, затем обновляет подписи.

Open_Click читает изображение через OpenFileDialog, пропорционально вписывает его
по центру белого холста и закрывает исходный файл. Открытие создаёт отдельную
вкладку и запоминает путь к исходному изображению.
Save_Click сохраняет Bitmap активной вкладки по её текущему пути без диалога.
Если вкладка ещё не сохранялась, открывается Save As.
SaveAs_Click предлагает выбрать имя и формат через SaveFileDialog.
Для нового рисунка диалог открывается в папке из Settings. Папка создаётся
при применении настроек или первом сохранении. Для рисунка с существующим путём
Save As открывается в папке этого файла, а Save сохраняет по прежнему пути.
SaveDocumentToFile записывает Bitmap указанной страницы и только после успешного
сохранения запоминает выбранный путь и SavedVersion. Это позволяет сохранить
даже неактивную страницу перед её удалением или закрытием приложения.
SaveToFile вызывает этот метод для текущей страницы.
Последующие Save записывают изменения в этот файл.
Формат определяется расширением PNG, JPG/JPEG или BMP.
Ошибки открытия и сохранения показываются в MessageBox.

Dispose освобождает Bitmap и оба стека истории всех документов, а также компоненты формы.
OnShown устанавливает размер начального холста после разворачивания окна.
Размер существующего рисунка сохраняется при изменении окна: при необходимости
появляется прокрутка, поэтому уменьшение окна не обрезает рисунок.
New создаёт холст размером с текущую доступную область.
Если Settings задаёт явный размер, новые холсты используют его.
